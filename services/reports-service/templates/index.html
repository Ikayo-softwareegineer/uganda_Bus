Endpoints

Report endpoints need the X-Service-Key header, so only the PHP backend can call them.

EndpointWhat it returns
GET /healthIs the service up and is the database found (no key needed)
GET /reports/summaryBookings, revenue, seats sold, cancellation rate, cash still due
GET /reports/revenue-by-routePaid revenue per route
GET /reports/occupancy?days=7How full upcoming trips are, per route
GET /reports/bookings-per-day?days=14Bookings and revenue for each recent day
GET /reports/payment-methodsBookings per payment method
GET /reports/operatorsSeats sold and revenue per bus operator
GET /reports/allEverything above in one response (used by the admin page)
